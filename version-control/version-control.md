## Why this matters

Every researcher independently invents the same filing system: `analysis_v2.py`, `analysis_v2_fixed.py`, `analysis_v2_fixed_USE_THIS.py`. It is not a discipline problem — it is a missing tool. You need to be able to answer "what did this look like last Tuesday" and "what changed since my supervisor last read it", and folders cannot answer either.

Git records your work as a series of labelled snapshots you can return to at any time. That is the whole idea. Collaboration, backups, and publishing your code alongside a paper all fall out of it for free.
