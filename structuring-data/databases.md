## Why this matters

Spreadsheets are excellent until the same entity starts appearing in several files under slightly different names. Then every update has to happen in five places, every question needs another manual join, and nobody can tell which copy is authoritative.

A database stores each fact once, enforces the relationships between your tables, and lets you ask questions you did not anticipate when you set it up. You do not need to be a software developer to get real value from one.
